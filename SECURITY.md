# Security Policy

Do not open a public issue containing credentials, private messages, profile files, or details that could expose an account.

Use GitHub's private vulnerability reporting for this repository when available. Include the affected version, reproduction steps, and impact, but omit secrets and personal data. Do not test reports against real accounts or platform services without authorization.

If a credential has been exposed, revoke or rotate it in the service that issued it. Removing it from the current tree does not remove it from public Git history.
