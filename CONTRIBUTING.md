# Contributing

1. Fork the repository and work on a focused branch.
2. Use Node.js 20 or newer. Run `npm ci`, `npm test`, and `node --check` for changed JavaScript files.
3. Keep tests offline: use synthetic identities, temporary directories, and mocked APIs. Do not use personal profiles, cookies, messages, model services, or live platform accounts.
4. Explain behavior changes and platform-facing effects in the pull request. Include upstream attribution when adapting third-party code.
5. Do not add dependencies, automatic posting, account data, analytics, or background services without documenting their behavior and review requirements.

By submitting a contribution, you agree that your changes are provided under the repository's MIT License unless the contribution identifies different third-party terms.
